# Clip Relay visual language → Clip AI

This refresh is intentionally visual-only. The underlying Clip AI v20.1 worker, API contracts, local Whisper flow, ranking, rendering, project storage and system checks are unchanged.

## Shared design language

- Near-black base (`#090a0f`) with subtle violet/cyan ambient light
- Layered glass-like panels instead of flat black cards
- Violet primary actions with restrained glow
- Compact controls, muted secondary copy and consistent rounded geometry
- Green/amber/red semantic states matching Clip Relay
- Matching Clip Relay-style brand tile generated with CSS (no font or image dependency)

## Main surfaces refreshed

- Create / upload hero
- YouTube project flow
- Analysis progress
- Best 3 results and detailed editor cards
- Projects library
- System / preflight page
- Onboarding modal

No functionality was removed or added in this package.

## Navbar polish

The navigation is now a floating glass bar with a complete rounded border, subtle violet/cyan depth, and responsive edge spacing. This avoids the previous visual impression that the header background simply stopped near the right edge on wide screens.
