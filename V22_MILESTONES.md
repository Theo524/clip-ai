# Clip AI v22 milestone map

- M1 — Context Foundation: complete.
- M2 / M2.1 — Smarter Clip Intelligence + memory-safe Whisper: complete.
- M3 — Titles & Social Metadata: complete.
- M4 / M4.2 — Visual & Caption Intelligence + corrected Anime cinematic framing: complete.
- M5 — Editing & Workflow: complete.
- **M6 — Performance / Cleanup / Freeze: complete.** Dual-audio selection, stable selected-track normalization, source/cache cleanup, bounded transcript cache, lightweight performance metrics, final stress/regression hardening and v22 feature freeze.

## Frozen v22 defaults worth preserving

- Anime Auto: Focus + Compact central frame on true black canvas.
- Anime Auto captions: Cinematic, low inside the picture; face tracking must not push them to the middle.
- Clip duration is story-aware rather than fixed; natural beginnings/endings beat arbitrary cutoffs.
- Best 3 should be diverse when good distinct scenes exist.
- Public Clip AI remains independent from private Clip Relay.

After M6, prefer bug fixes over new features until there is a clear need for a v23 milestone.
